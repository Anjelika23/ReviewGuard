REST API Documentation

ReviewGuard provides low-latency RESTful APIs for real-time review inference, movie trust analytics, and health telemetry.

⚡ Check Health Status
GET /health/ Zero-Auth • Telemetry

Health and orchestration probe. Used by cloud reverse proxies (Render, Kubernetes, AWS, Cloudflare) for liveliness and readiness probes.

Example Request
curl -X GET https://your-domain.onrender.com/health/
Sample 200 OK Response
{
  "status": "healthy",
  "service": "ReviewGuard",
  "version": "2.0.0",
  "database": "connected",
  "model_loaded": true,
  "total_movies": 40,
  "total_reviews": 7426
}
POST /api/predict/ Stateless • CSRF Exempt

Evaluates an incoming review payload using dual-feature stacking (TF-IDF NLP stylometry + historical velocity context).

Example cURL Request
curl -X POST https://your-domain.onrender.com/api/predict/ \ -H "Content-Type: application/json" \ -d '{ "movie": "{{ sample_id }}", "user_id": "U_tester_99", "rating": 5, "review_text": "Best movie ever! 10/10 masterpiece, must watch, nothing negative!", "account_age_days": 1 }'
Sample 200 OK Prediction Response
{
  "status": "success",
  "movie": "{{ sample_id }}",
  "prediction": {
    "fake_probability": 0.8612,
    "fake_percentage": 86.1,
    "is_fake": true,
    "risk_level": "Critical Risk",
    "label": "Likely fake",
    "reasons": [
      "Generic, templated superlative language",
      "Short extreme rating with no specifics",
      "Very new account (1 day old)"
    ]
  }
}
GET /api/trust/<product_id>/ Analytics Query

Returns the Verified Trust Score, inflation delta, and review integrity metrics for any catalog item.

Example Request
curl -X GET https://your-domain.onrender.com/api/trust/{{ sample_id }}/
Sample 200 OK Response
{
  "product_id": "{{ sample_id }}",
